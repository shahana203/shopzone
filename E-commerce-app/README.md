
# 🛍️ ShopZone – E-commerce Website

ShopZone is a responsive e-commerce web application built using React and Tailwind CSS. It allows users to browse products, search and filter items, manage their shopping cart, and complete a checkout process.

## 🚀 Live Demo

[Visit ShopZone]
https://shopzone-gules.vercel.app/

## ✨ Features

- **Product Listing:** Fetch and display products using the Fake Store API.
- **Search Products:** Search for products by name.
- **Category Filtering:** Filter products based on categories.
- **Price Filtering:** Filter products within a selected price range.
- **Sorting:** Sort products by price, rating, and name.
- **Product Details:** View individual product information.
- **Shopping Cart:** Add, remove, increase, and decrease product quantities.
- **Cart Management:** View cart items and calculate the total price.
- **Checkout:** Complete the checkout process.
- **Order Success:** Display an order confirmation page.
- **Offers:** Browse available offers.
- **New Arrivals:** Explore recently added products.
- **Contact Page:** View the contact page.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/shahana203/shopzone.git
```

### 2. Navigate to the project folder

```bash
cd shopzone/E-commerce-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### 5. Build for production

```bash
npm run build
```
